# エラー・情報メッセージ（現行実装）

[← 要件定義書](../requirements.md) / [入力チェック](input-validation.md)

以下はコードで定義された文言。以前のE-xxx/I-xxxは設計書内の管理用番号であり、現行APIレスポンスや画面にエラーコードとして実装されていない。未実装の日本語必須エラーやトーストを実装済みとして扱わない。

## 画面の独自メッセージ

| 文言 | 対象・条件 | 表示 |
| --- | --- | --- |
| 確認用パスワードを入力してください | 登録・確認用空欄 | フォーム内 |
| パスワードが一致しません | 登録・確認用不一致 | フォーム内 |
| パスワードは英字と数字を含めてください | 登録・文字構成違反 | フォーム内 |
| このメールアドレスは既に登録されています | 登録APIが409 | フォーム内 |
| 登録に失敗しました。しばらく経ってから再度お試しください | 登録のその他失敗 | フォーム内 |
| メールアドレスまたはパスワードが正しくありません | ログイン失敗（通信障害も同じ表示） | フォーム内 |
| 期限に過去の日付は指定できません | 詳細編集・過去期限 | 詳細モーダル内 |
| データの保存に失敗しました。時間をおいて再度お試しください | 詳細保存/削除・ニックネーム保存失敗 | 各フォーム内 |
| ニックネームを入力してください | ニックネーム編集・trim後空欄 | ヘッダー内 |
| 50文字以内で入力してください | ニックネーム編集・長さ超過 | ヘッダー内 |
| データの取得に失敗しました。バックエンドが起動しているか確認してください。 | ボードの一覧取得失敗 | ボード内 |
| データの取得に失敗しました | 完了一覧・検索失敗 | 一覧内 |
| カラムの削除に失敗しました。 | カラム削除APIのmessageが得られない場合 | カラム内 |
| カードはありません / 一致するタスクはありません | ボードの通常/検索表示でカラムが0件 | カラム内 |
| 完了タスクはありません | 完了一覧の初期表示が0件 | 一覧内 |
| 該当するタスクはありません | 完了検索後が0件 | 一覧内 |

追加モーダル/カラム追加には保存失敗の独自表示がない。HTMLのrequired/minLength/maxLength/type=email/dateによる制約はブラウザ標準動作、タイトル・カラム名の空欄はボタン無効化で防ぐ。入力欄ごとの日本語エラーをすべて独自実装しているわけではない。

## 確認ダイアログ（window.confirm）

| 文言 | 操作 |
| --- | --- |
| このタスクを削除しますか？ | ボードカード右上の× |
| このカードを削除してもよろしいですか？ | 詳細モーダルの削除する |
| このカラムを削除してもよろしいですか？ | カスタム列の削除 |

削除の結果は画面/状態により異なる（[現行対応表](../implementation-status.md)）。

## APIの例外処理

| HTTP | 条件 | JSON/処理 |
| --- | --- | --- |
| 400 | Bean Validation失敗 | message=「バリデーションエラー」、errorsにフィールド別文言（ロケール依存） |
| 404 | リストが見つからない | EntityNotFoundExceptionのmessage。「リストが見つかりません: ID」 |
| 404 | タスク/移動先リストがない・他ユーザー所有 | ResponseStatusException。Task not found / List not foundの理由で拒否。専用の日本語変換なし |
| 409 | デフォルトカラム削除 | message=「デフォルトカラムは削除できません」 |
| 409 | 未アーカイブタスクが残るカラム削除 | message=「タスクが残っているカラムは削除できません」 |
| 409 | 登録メール重複 | AuthControllerが空ボディの409を返し、登録画面側で日本語表示 |
| 401 | 保護APIへの未認証アクセス | Spring SecurityのエントリーポイントがUnauthorizedを返す |

タスク通信層は401でJWTを削除して/loginへ移動するが、「セッションの有効期限が切れました」の専用表示は未実装。認証API通信は別実装であり、全画面共通の401処理ではない。共通の通信エラートーストや「予期しないエラーが発生しました」の汎用表示も未実装。
